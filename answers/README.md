# Відповіді до лабораторної роботи № 1

1. Тип задовольняє інтерфейс, якщо його набір методів відповідає контракту. Окреме оголошення `implements`, як у Java, не потрібне.
2. Одержувач за значенням отримує копію значення. Одержувач за вказівником дає доступ до вихідного об’єкта й дозволяє змінювати його поля. Методи з вказівниковим одержувачем також впливають на набір методів, потрібний для інтерфейсу.
3. Горутини мають невеликі початкові стеки, які зростають за потреби. Планувальник Go розподіляє їх між потоками ОС. Фактичне споживання пам’яті залежить від роботи кожної горутини.
4. Детектор фіксує одночасні несинхронізовані звернення до тієї самої області пам’яті, коли принаймні одне є записом. Він охоплює код, що виконався під час конкретного запуску.
5. Вона очікує завершення групи завдань. `Add` перед запуском горутини гарантує, що `Wait` врахує завдання, а `Done` позначає його завершення.
6. `Mutex` надає винятковий доступ до критичної секції зі спільним станом. Канал передає результати споживачу, який може одноосібно оновлювати статистику.
7. Обидві операції спричинять паніку. У проєкті канал закриває один координатор після завершення всіх відправників.
